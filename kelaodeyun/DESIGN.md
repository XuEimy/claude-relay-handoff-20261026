# 网站视觉与子页面

本次沿用首页已确认的视觉：暖白背景、深炭色正文与主按钮、陶土色交互强调、衬线页面标题、细线分隔。没有替换首页版面。

## 用户任务

- 产品信息：模型与价格、下载、使用指南、帮助、隐私与服务说明。
- 账户操作：登录、注册、账户概览、安全设置。
- 付款流程：选择金额及渠道 → 订单付款 → 查询支付结果 → 查看到账记录。

## 共用规则

- 顶部导航与首页保持一致，登录或账户入口位于最右侧。
- 子页面标题使用现有 Claude Serif / 中文宋体；表单、金额标签、表格使用现有无衬线字体。
- 页面内容最大宽度 1320px；登录及结算采用较窄内容区；800px 以下按任务重排为单列。
- 操作控件有 hover、focus、disabled 和 busy 状态；异步内容区区分加载、错误、空记录及成功。
- 真实费率、余额、渠道与订单状态来自现有 API。未配置支付不可下单，下载未提供则禁用。
- 付款成功必须由服务端查询结果确定，不因前端点击或跳转自行入账。
