# Anthropic 官网视觉拆解与 kelaodeyun 实现

采集日期：2026-10-26。参考地址：[Anthropic 官网](https://www.anthropic.com/)。采集方式：复用本机已打开的日常 Chrome，通过已有扩展连接观察页面；没有启动自动化浏览器。现有 Claude 聊天还原保留在相邻的 `claude-reverse-20261026` 文件夹。

## 已观察到的视觉规范

| 项目 | 实测与观察 | kelaodeyun 的处理 |
| --- | --- | --- |
| 页面底色 | `rgb(250,249,245)`，即 `#faf9f5` | 延用暖纸色；聊天区域用更浅底色 |
| 文字 | `rgb(20,20,19)`，即 `#141413` | 使用接近的墨色 `#191916` |
| 导航底色 | `#f5f4ed`，胶囊轮廓 | 紧凑胶囊导航、浅色描边 |
| 导航字号 | 13px，Anthropic Sans | 中文系统无衬线，桌面 12px |
| 品牌位置 | 桌面居中；手机左侧紧凑标识 | 自有 k 标记与 kelaodeyun 字标 |
| 首段标题 | 衬线正文中嵌入无衬线强调；不是常见的居中口号 | 中文宋体与黑体混排，保持段落式大标题 |
| 桌面标题 | 1440×900 视口下约 40.56px / 50.70px；正文容器 x=80、宽1265px | 80px 级边距，响应式字号与中文行高 |
| 大屏标题 | 2504px 视口下 48px / 60px；主体最大宽1760px | 保留宽容器和最大宽度限制 |
| 手机标题 | 390×844 视口下 25px / 32.5px；x=32、宽311px | 32px 级边距，26px 中文字号 |
| 主视觉标题 | 桌面约51.62px，手机32px，无衬线 | 品牌场景改为“与好想法对话”，加大中文主视觉字号 |
| 内容卡片 | 桌面三栏，文章式层级；标题约21.35px；手机堆叠 | 三个使用场景：写作、学习、代码 |
| 装饰画面 | 低饱和纸片、照片与几何图案拼贴；中心留白；可暂停 | 自制 SVG 几何拼贴，不复用品牌图像或新闻内容 |
| 动效与菜单 | 首屏提供暂停；手机菜单为独立展开层 | 提供暂停、减少动态偏好、手机菜单与 Escape 关闭 |

实际视口的可排版宽度受系统滚动条影响：390px 视口中，页面 clientWidth 为375px。这解释了实测边距和容器宽度的差异。

源站字体名来自 computed style：`anthropicSerif` / `anthropicSans` 及其 fallback。新站使用系统字体：macOS 的 Songti SC / PingFang SC，Windows 的 Microsoft YaHei 等；当前版本不依赖 Google Fonts、外部图床或字体 CDN。不同系统字体会有细小排版差异。

## 能确定和不能确定的实现信息

DOM 中观察到 `/_next/static/chunks/*.css` 资源路径，这支持“使用 Next.js 静态资源管线”的判断，不能据此确定具体 Next.js 版本或服务器架构。16 条样式资源地址保存在 `evidence/anthropic/styles.json`。普通 HTTP 下载这些资源失败，因此未将原站 CSS 归档，也未声称读取了其完整源码。

本次对官网的逆向范围是可见视觉、响应式结构、导航展开和公开 DOM。没有获得其服务端代码、内部接口、数据库、私有设计系统或完整动效实现。kelaodeyun 为按这些观察实现的品牌化版本，不是像素级完整镜像，也不表示与 Anthropic 存在官方关系。

## 从官网到聊天服务

网站首页负责介绍与引导；聊天区负责实际任务；账户区负责费用；后台负责运营配置。四个区域共享纸色、细线、克制的圆角与字体层级，信息密度按场景变化。

- `/`：官网、使用场景、FAQ。
- `/chat`：会话历史、搜索、重命名、删除、模型选择、Markdown、流式输出和停止。
- `/login`：登录、注册；空数据库首次显示管理员初始化。
- `/billing`：余额、模型费率、用量、充值订单、兑换码和修改密码。
- `/admin`：用户状态、人工充值、渠道、模型费率、兑换码、支付订单、调用及操作日志。
- `/terms`、`/privacy`：与当前实现一致的预览说明，正式运营前需完善主体、联系方式及政策。

结构：浏览器 → 本站 Node API → 授权模型服务；浏览器不接触渠道密钥。会话、余额、用量与订单使用 SQLite 持久化。模型密钥在库内以 AES-256-GCM 加密，密码为加盐 scrypt 哈希，登录使用服务端会话和 HttpOnly Cookie。

## 中国大陆使用方向

已实现中文界面、人民币金额、北京时间、系统中文字体、支付宝网页支付适配、微信 Native 扫码支付适配、兑换码与管理员充值、备案信息展示字段。在线支付未配置商户时禁用入口，不显示虚假收款码。

“按中国大陆用户习惯设计”不等于“已经具备公开运营条件”。当前没有域名部署、运营主体确认、模型服务商适用条件核验、真实支付联调或运营内容治理接入；这些需要在实际部署和商户资料明确后完成。没有绕过登录、地区限制或取用 Claude 网页会话凭据。

支付实现依据：
- [支付宝网页收款接入指南](https://aipay.alipay.com/docs/vibe-pay/ai-web-app-payment-qianyi/ai-web-app-payment-integration-guide.html)：页面支付、服务端验签、查询/通知确认结果。
- [微信 Native 下单](https://pay.wechatpay.cn/doc/v3/merchant/4012791877)：生成支付码链接。
- [微信 API v3 签名与验签](https://pay.wechatpay.cn/doc/v3/merchant/4012365342)：请求、响应及通知验签。
- [Anthropic API 概览](https://platform.claude.com/docs/en/api/overview)与[流式输出](https://platform.claude.com/docs/en/build-with-claude/streaming)：Messages 协议接入；模型 ID 由实际授权渠道配置。
