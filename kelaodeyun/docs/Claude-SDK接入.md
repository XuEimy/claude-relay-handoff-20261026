# Claude 官方 SDK 接入

服务端使用 `@anthropic-ai/sdk`（当前锁定安装 1.3.0），不向浏览器暴露渠道密钥。网页仍使用本站已有 Claude 风格聊天界面。

## 配置真实渠道

1. 登录管理员账户，打开「管理后台 → 模型渠道」。
2. 添加渠道。Anthropic 官方根地址为 `https://api.anthropic.com`，填入自己有权限使用的 API 密钥。兼容 Anthropic Messages 协议的授权渠道可填写自己的 HTTPS 根地址；末尾带 `/v1` 也会规范化。
3. 保存后点击「读取模型」。服务端通过官方 SDK 查询该渠道的 `/v1/models`，展示前 100 项，并在添加模型时提供 ID 建议。这一步只查询模型列表，不发起生成，也不扣本站余额；上游可用性、实际生成权限和额度仍需实际对话验证。
4. 在下方添加模型：填写显示名称、接口返回的模型 ID、所属渠道、人民币输入/输出费率和单次最大输出。保存后模型会出现在聊天页。
5. 给测试用户充值本站余额，选择模型开始对话。模型费用会按上游返回的输入/输出 token 和配置费率结算。

部分兼容渠道不提供模型列表。读取失败时可手动填写该渠道文档确认的模型 ID；不能仅凭模型列表失败断言生成接口不可用。

## 请求和结算

- 服务器解密所选渠道的密钥，由 SDK 生成认证与 API 版本头；每次固定使用该渠道根地址，不继承本机其他 SDK 的地址或凭据。
- `messages.create({ stream: true })` 使用官方 SSE 解码，保持现有网页的 meta / delta / done / error 事件接口。
- 生成前预留额度；正常完成按已报告的 token 结算并退回差额。停止、断流或上游错误时保存已收到的文本，只结算已报告的用量，释放未用预留。未报告的 token 费用不估算转嫁给用户。
- 等待超过 120 秒会取消请求。用户点击停止或离开导致连接关闭时也会取消上游；同一账户不能同时生成两条回复。
- 自动重试关闭，防止网络问题导致重复生成。SDK 日志和遥测关闭，错误响应不会包含上游错误体、请求头或密钥。
- API 版本默认使用已安装 SDK 的值。只有渠道要求时才设置 `ANTHROPIC_VERSION`；工作区头可使用 `ANTHROPIC_WORKSPACE_ID`。

## 验证边界

本地 `scripts/demo-server.mjs` 保留隔离的 `data/demo.db`，上游请求由模拟 fetch 响应，仍经过真实官方 SDK 的请求生成和 SSE 解码。演示模型名称、费率和回复不代表真实模型接入。
