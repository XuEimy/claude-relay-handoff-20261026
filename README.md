## 开发入口

进入 `kelaodeyun-desktop/`，使用其 `package.json` 指定的 Node 26.12.1、pnpm 12.14.0；详细步骤见开发交接。先构建 Linux x64 远端运行程序，再启动桌面开发环境。服务器凭据由开发者自行在本机配置。

本次提交不包含个人 SSH 地址、账号密码、私钥、连接档案、运行数据库、Claude 会话数据、依赖缓存及 App 安装包。通用 SSH 功能源代码包含在内。

`MANIFEST.sha256` 对应 2026-10-27 的历史交付，不代表本次更新；本次以 Git 提交为版本依据。上游 T3 Code 介绍与文档保留于桌面源码目录，产品当前状态以本交接为准。
